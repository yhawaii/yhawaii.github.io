传统传输的安全隐患

网络暴露风险

USB、云存储、邮件传输都经过第三方。数据可能被截获、存储、分析。

断网环境限制

安全隔离环境禁止网络连接。传统文件传输方式完全失效。

临时设备困境

现场运维、客户演示时，两台设备之间没有可靠传输渠道。

隐私泄露担忧

敏感文件上传到云端，你永远不知道谁在后台查看。

核心特性

◈

零依赖运行

纯静态 HTML 文件，无需安装、无需配置、无需服务器。浏览器直接打开即用。

generator.html → 发送端
scanner.html → 接收端
无构建步骤 / 无 npm / 无后端
◈

完整性保障

三层校验机制：分片 CRC32、文件整体哈希、大小验证。数据损坏自动重试。

v2 协议 → 元数据含 hash + size
每帧 → 独立 CRC32 校验和
拼装 → 逐片完整性检查
◈

容错传输

循环发送机制，漏扫分片自动补齐。进度实时可视化，缺失分片一目了然。

发送端 → 循环显示直到手动停止
接收端 → 分片网格状态显示
重扫 → 已收分片自动去重
◈

高效编码

直接 Base64 编码，无 UTF-8 膨胀。500 字节分片，QR 码容量利用率达 75%。

适用场景

安全运维

隔离服务器、断网环境的配置文件、日志传输。无需打破安全边界。

现场演示

客户现场、会议演示时快速传输文件。无需寻找 Wi-Fi 或配置网络。

隐私传输

敏感文档、密钥、证书等。数据不经过任何第三方服务，端到端物理隔离。

应急备份

网络中断时紧急文件备份。手机 → 电脑，电脑 → 服务器，纯物理方式。

跨平台

Windows、macOS、Linux、手机浏览器通用。无客户端，无兼容性问题。

取证场景

数字取证中从隔离设备提取数据。保持证据链完整性，无网络痕迹。

立即体验

打开两个浏览器窗口，一台发送，一台接收。
无需安装，无需注册，无需网络。
